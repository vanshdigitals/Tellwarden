## 2. Domain availability and trademark clearance are different checks

- A **domain check** (RDAP or WHOIS) shows whether a string is registered in one registry. It says nothing about who has rights to the name.
- A **trademark search** looks at registered and pending marks and look-alike names. A clean search still does not cover unregistered prior use or foreign marks.
- A free domain plus a clean register search is **not** legal clearance. This project makes no claim that any name is legally available or unique.

Scoring notes:

- Domain and TM screening: 2 means "unverified, not known to be clean". 1 means a known conflict (signalkeep.com looks registered).
- Tellwarden: coined compound, zero exact hits. "Tell" fits the scanner's reporting. "Warden" fits the IDS guard role. Spelling is unambiguous. Search differentiation is held at 3 because of the shared "warden" suffix.
- Scarpwatch ties on points but embeds "arpwatch", a same-field tool, so it carries a higher confusion risk.

## 8. Product category findings (for context)

- **[Verified]** Header scanners with grades are already common student projects (several HeaderHawk repositories). Nikto is a GPLv2 command-line web server scanner ([Wikipedia](https://en.wikipedia.org/wiki/Nikto_(vulnerability_scanner))).
- **[Docs, not re-fetched]** Mozilla HTTP Observatory and securityheaders.com grade headers. ZAP baseline runs a short spider plus passive rules. Wazuh rules are XML with frequency correlation. fail2ban bans IPs from log patterns. Sigma is a generic YAML detection-rule format.
- **[Recommendation]** What Tellwarden can honestly offer: a teaching UI that explains why each check or rule exists, editable rule thresholds with evidence trails, a documented SSRF-safe scanner design, and rules stored as data. It does not replace the tools above.
